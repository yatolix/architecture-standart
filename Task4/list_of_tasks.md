# Задачи для реализации функционала предоставления депозитных ставок кол-центра в рамках общего MVP по депозитам.

В документе перечислены основные задачи для разработки предоставления депозитных ставок кол-центрам для консультации клиентов. Задачи даются в разрезе каждой системы. Подразумевается что остальные работы по реализации MVP депозитов будут выполнены согласно `ADR-0001-MVP-deposits.md` из **Task3**.

## АБС

1. Реализовать в `rates-service` REST контроллер для получения всех ставок по депозитам (можно сделать путём доработки REST контроллера предназначенного для получения ставок Интернет-банком)
2. Реализовать формирование и загрузку CSV файла со ставками по SFTP в систему партнёрского кол-центра
3. Интегрировать формирование файла в процессы обновления ставок чтоб файл всегда содержал актуальную информацию
4. Настроить безопасное подключение к SFTP партнёрского кол-центра
5. Сконфигурировать SFTP для локального тестирования
6. Тестирование REST контроллера
7. Тестирование отправки файлов

## Система кол-центра банка

1. Реализовать обращение к REST контроллеру `rates-service` для получения всех ставок
2. Реализовать кэширование ставок
3. Реализовать справочный экран с таблицей ставок
4. Тестирование

## Система партнёрского кол-центра

1. Поднять и настроить SFTP, в т.ч. выпуск сертификатов
2. Реализовать отображение ссылки для открытия CSV файла из UI (в будущем можно будет сделать и парсинг файла)
3. Тестирование
